# Ghostpost landing page

A small static website for Ghostpost. Open `index.html` locally or deploy these files to any static host.

The public legal URLs are `terms.html` and `privacy.html` relative to the deployed site; both links are visible in the header and footer of the home page.

Before using the legal pages in a developer portal, replace `CONTACT_EMAIL_HERE` in both pages and review the data handling language against the real service. TikTok also requires ownership verification for configured URLs and reviews the official website, not just the legal links.
